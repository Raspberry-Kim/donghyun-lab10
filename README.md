# 동현몬 v0.12

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23914029.svg)](https://doi.org/10.5281/zenodo.23914029)

동현랭으로 시작 마을·포동이의 성격·야생 출현율·소지금·시드를 정하고 나서는 작은 몬스터 RPG다.
동현 시리즈의 열 번째 작은 실험이다. 주인공 동현의 뒤를 실험실의 강아지 포동이가 따라다닌다.

- 조작: 키보드(방향키 · X 말걸기·확인 · Z 취소 · S 동현몬 · A 상태 · Enter 메뉴) 또는 블루투스·USB 게임패드(닌텐도 배치 A=X키 확인 · B=Z키 취소 · X=S키 동현몬 · Y=A키 상태 · +=메뉴). 휴대폰은 화면 단추. 자세한 것은 아래 [조작](#조작).
- 지도: 하얀마을(집·연구소·회복소) → 산책로(긴 풀·트레이너 2) → 동현시(회복소·가게·체육관). 화면 320×192(가로 20칸 × 세로 12칸, 16px), 동현전·동현워 창 크기에 맞춘 가로로 긴 비율.
- 동현몬 13종: 포동이, 라이언·슈슈·예쁜꼬마선충(동현파), 초파리(동현초), 보병·전차·전투기(동현전), 창병·궁수·기사(동현워), 꼬리콥터(동현콥), 둠가이(동현둠). 속성 6(노말·격투·벌레·비행·강철·불), 기술 27.
- 전투: 턴제, 기술 4개, 속성 상성·급소·능력 단계. 야생은 동현볼로 잡고(체력이 낮을수록 잘 잡힘), 트레이너는 시선에 걸리면 승부를 걸어온다.
- 끝: 동현시 체육관 관장 동현(전차·기사·둠가이)을 이기면 배지를 얻고 끝난다.

## 동현몬 출전 규약

| 변수 값 | 뜻 | 범위 |
|---|---|---|
| 1 | 시작 마을 | 1 하얀마을 · 2 산책로 · 3 동현시 · 기본 1 |
| 2 | 포동이 성격 | 1 균형 · 2 공격형 · 3 방어형 · 4 재빠름 · 5 느긋함 · 기본 1 |
| 3 | 야생 출현율 | 0 없음 · 1 기본 · 2–5 점점 자주 · 기본 1 |
| 4 | 소지금 | 0–9999원 · 기본 1000 |
| 5 | 시드 | 정수 · 기본 1 |
| 6 | 출전 | 마지막에 둔다 |

`뿡뿡 번호~뿡뿡뿡` 다음 줄에 `뿡뿡 값~뿡뿡뿡`을 출력하는 식으로 쓴다. 예제는 시작 마을 → 성격 → 출현율 → 소지금 → 시드 순서로 적었다.

## 조작

방향키 걷기·고르기 · X 말걸기·줍기·확인 · Z 취소·대화 넘기기 · S 동현몬 목록(순서·상처약) · A 지금 상태 한 줄 · Enter 메뉴(동현몬·가방·도감·저장·불러오기·포기) · M 효과음. 동현전·동현워·동현크와 같은 키 배치다. 좁은 화면과 터치 기기에서는 화면 버튼이 나온다.

게임패드(닌텐도 배치): A 말걸기·확인 · B 취소 · X 동현몬 · Y 상태 · + 메뉴 · 십자·왼 스틱 걷기. 블루투스·USB 게임패드를 OS에서 짝지어 두면 브라우저가 바로 읽는다(Gamepad API, Safari·Chrome·Firefox·아이폰 Safari). 단추를 한 번 누르면 "게임패드 연결됨"이 상태 줄에 뜬다. 기준은 닌텐도 배치이고 네 단추는 자리로 짝을 맞춘다(오른쪽=X키 · 아래=Z키 · 위=S키 · 왼쪽=A키). 닌텐도·8BitDo(닌텐도 배열) 패드는 브라우저 표준 배치가 자리 기준이라 설정 없이 바로 A=X키·B=Z키다. 드물게 A와 B가 거꾸로 들어오면 −(Select)를 한 번 눌러 바꾼다(다시 누르면 원래대로, 패드 이름별로 브라우저에 남는다).

## 저장

Enter 메뉴에서 브라우저 칸 3개(`donghyunmon:slot1..3`) 또는 `.dhsave` 파일로 저장하고, 출전 준비 화면이나 메뉴에서 불러온다. 지도 위에서만 저장할 수 있다. 동현전·동현워·동현크와 같은 방식이다.

## 파일

- `src/` 원본(donghyun.js 실행기 · sprites.js 도트 · data.js 자료 · engine.js 규칙 · render.js 화면 · examples.js 예제 · sfx.js 효과음 · gamepad.js 게임패드 · app.js 화면 연결)

- `node build.cjs` → `dist/index.html`(단일 파일)과 루트 `index.html`
- `qa/smoke.cjs` Playwright 점검(예제 13개 · 연구소 선물 · 야생 포획 · 체육관 배지 · 회복소 · 저장/불러오기)
