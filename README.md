# 동현몬 v0.25

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23914029.svg)](https://doi.org/10.5281/zenodo.23914029)

동현랭으로 시작 마을·포동이의 성격·야생 출현율·소지금·시드를 정하고 나서는 작은 몬스터 RPG다.
동현 시리즈의 열 번째 작은 실험이다. 주인공 동현의 뒤를 실험실의 강아지 포동이가 따라다닌다.

- 조작: 키보드(방향키 · X 말걸기·확인 · Z 취소 · S 동현몬 · A 상태 · Enter 메뉴) 또는 블루투스·USB 게임패드(닌텐도 배치 A=X키 확인 · B=Z키 취소 · X=S키 동현몬 · Y=A키 상태 · +=메뉴). 휴대폰은 화면 단추. 자세한 것은 아래 [조작](#조작).
- 지도: 하얀마을(집·연구소·회복소) → 산책로(긴 풀·트레이너 2) → 동현시(회복소·가게·체육관 1) → 뚱띠 고개 → 뿡뿡항(항구·체육관 2) → 또치 숲 → 꽥꽥마을(체육관 3) → 멈춤 길 → 신중동역(대합실·승강장·역장 오겡끼). 하얀마을 서쪽 호숫길은 배지 둘이면 꽥꽥마을로 질러 간다. 지도 23장 · 10,736칸(v0.17의 2,128칸의 5.0배). 화면 320×192(가로 20칸 × 세로 12칸, 16px), 동현전·동현워 창 크기에 맞춘 가로로 긴 비율.
- 동현몬 16종: 포동이, 라이언·슈슈·예쁜꼬마선충(동현파), 초파리(동현초), 보병·전차·전투기·폭격기(동현전), 창병·궁수·기사·정찰기병·팔라딘(동현워), 꼬리콥터(동현콥), 둠가이(동현둠). 속성 6(노말·격투·벌레·비행·강철·불), 기술 27.
- 전투: 턴제, 기술 4개, 속성 상성·급소·능력 단계. 야생은 동현볼로 잡고(체력이 낮을수록 잘 잡힘), 트레이너는 시선에 걸리면 승부를 걸어온다.
- 상자: 동현몬은 여섯까지 데리고 다닌다. 일곱째를 잡으면 누구를 연구소 상자에 맡길지 고르고(Z면 새 동현몬을 맡긴다), 회복소·연구소에서 상자를 열어 데리고 있는 동현몬과 바꾼다. 상자에 든 동현몬은 체력이 가득 찬다.
- 이야기: 세상 프로그램을 멈추려는 멈춤단이 길을 막는다. 동현시 관장 동현(강철·불), 뿡뿡항 관장 뿡뿡(하늘), 꽥꽥마을 관장 꽥꽥(격투)의 배지 셋을 모으면 멈춤 길 끝 신중동역 문이 열리고, 승강장에서 멈춤단 우두머리 역장 오겡끼(전차·폭격기·기사·둠가이·팔라딘)를 이기면 끝난다. 트레이너 32명.
- 성장: 싸우지 않은 동료도 절반의 경험치를 나눠 받는다. 포동이는 Lv24 앞발 펀치(격투), Lv30 전력 질주를 배운다. Z를 누른 채 걸으면 달린다.

## 동현몬 출전 규약

| 변수 값 | 뜻 | 범위 |
|---|---|---|
| 1 | 시작 마을 | 1 하얀마을 · 2 산책로 · 3 동현시 · 4 뿡뿡항 · 5 꽥꽥마을 · 기본 1 |
| 2 | 포동이 성격 | 1 균형 · 2 공격형 · 3 방어형 · 4 재빠름 · 5 느긋함 · 기본 1 |
| 3 | 야생 출현율 | 0 없음 · 1 기본 · 2–5 점점 자주 · 기본 1 |
| 4 | 소지금 | 0–9999원 · 기본 1000 |
| 5 | 시드 | 정수 · 기본 1 |
| 6 | 출전 | 마지막에 둔다 |
| 7 | 포동이 레벨 | 1–50 · 기본 5 |
| 8 | 동료 슈슈 레벨 | 0 없음 · 1–50 · 기본 0 |

`뿡뿡 번호~뿡뿡뿡` 다음 줄에 `뿡뿡 값~뿡뿡뿡`을 출력하는 식으로 쓴다. 예제 38개는 묶음별로 나뉜다: 처음 해 보기 → 명령 1~5 하나씩 → 명령 7(포동이 레벨)·8(동료 슈슈) → 여러 명령 함께 → 동현랭 문법 익히기(계산·변수·신중동·뭉치·신중동역).

## 조작

방향키 걷기·고르기 · X 말걸기·줍기·확인 · Z 취소·대화 넘기기 · S 동현몬 목록(순서·상처약) · A 지금 상태 한 줄 · Enter 메뉴(동현몬·가방·도감·저장·불러오기·포기) · M 효과음. 동현전·동현워·동현크와 같은 키 배치다. 좁은 화면과 터치 기기에서는 화면 버튼이 나온다.

게임패드(닌텐도 배치): A 말걸기·확인 · B 취소 · X 동현몬 · Y 상태 · + 메뉴 · 십자·왼 스틱 걷기. 블루투스·USB 게임패드를 OS에서 짝지어 두면 브라우저가 바로 읽는다(Gamepad API, Safari·Chrome·Firefox·아이폰 Safari). 단추를 한 번 누르면 "게임패드 연결됨"이 상태 줄에 뜬다. 기준은 닌텐도 배치이고 네 단추는 자리로 짝을 맞춘다(오른쪽=X키 · 아래=Z키 · 위=S키 · 왼쪽=A키). 닌텐도·8BitDo(닌텐도 배열) 패드는 브라우저 표준 배치가 자리 기준이라 설정 없이 바로 A=X키·B=Z키다. 드물게 A와 B가 거꾸로 들어오면 −(Select)를 한 번 눌러 바꾼다(다시 누르면 원래대로, 패드 이름별로 브라우저에 남는다).

## 저장

Enter 메뉴에서 브라우저 칸 3개(`donghyunmon:slot1..3`) 또는 `.dhsave` 파일로 저장하고, 출전 준비 화면이나 메뉴에서 불러온다. 지도 위에서만 저장할 수 있다. 동현전·동현워·동현크와 같은 방식이다.

## 파일

- `src/` 원본(donghyun.js 실행기 · sprites.js 도트 · data.js 자료 · engine.js 규칙 · render.js 화면 · examples.js 예제 · sfx.js 효과음 · gamepad.js 게임패드 · app.js 화면 연결)
- `tools/paint.py` 도트 그림 생성기 → `src/sprites.js`
- `tools/worldgen.cjs` 지도·사람 생성기 → `src/world.js`(뚱띠 고개·뿡뿡항·또치 숲·꽥꽥마을·멈춤 길·호숫길·신중동역과 실내)
- `node build.cjs` → `dist/index.html`(단일 파일)과 루트 `index.html`
- `qa/smoke.cjs` Playwright 점검(예제 38개 · 규약 7·8 · 연구소 선물 · 야생 포획 · 체육관 배지 · 회복소 · 저장/불러오기)
- `qa/box-tests.cjs` 연구소 상자 점검(일곱째 포획 때 교체·맡기기 · 회복소·연구소에서 바꾸기 · 쪽 넘김 · 빈 상자 · 직렬화)
- `qa/fuzz-battle.cjs` 전투 무작위 시험(야생·트레이너 전투를 무작위 입력으로 돌리며 매 걸음 그리기까지 수행 · 예외·멈춤 탐지)
- `qa/world-tests.cjs` 세계 자료 점검(지도 폭·그림·연결·출입구·사람 위치·관문)과 자동 완주 봇(세 체육관·신중동역까지 시드별 완주)
- `qa/fuzz-world.cjs` 전체 플레이 무작위 시험(걷기·문·대화·가게·전투·포획·상자·패배·저장 왕복을 섞어 판마다 15,000틀 · 예외·멈춤·상태 불변식 위반 탐지)

## 시리즈 연결

[동현랭](https://raspberry-kim.github.io/donghyun-lang/)과 열여덟 실험실을 상단 메뉴로 오간다. [동현테](https://raspberry-kim.github.io/donghyun-lab18/)는 고정 시점의 1인용 단식 테니스다. 데스크톱 메뉴는 동현랭이 두 줄 높이, 나머지는 9열×2줄이다. 모바일은 두 열이며 홀수 개일 때 동현랭만 두 칸 너비를 쓴다.
